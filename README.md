### 📒 [Ledger MI](https://github.com/lgndcraft2/ledger) — *CRM for Market Women*
> A multi-channel CRM built for Nigerian market women to record sales, track debts, and manage supplier relationships — accessible via **USSD, WhatsApp, and a React web dashboard**.

- **Tech:** Python · Flask · React · TypeScript · Neon (PostgreSQL) · Arkesel USSD · WhatsApp Cloud API · AI Agent (LLaMA / Groq)
- **Key Features:**
  - USSD interface for feature-phone users with no internet
  - WhatsApp bot that understands natural language voice notes and text (e.g. *"Sold 2 bags of rice to Rose for 5k"*)
  - AI-generated business summaries and reports on demand
  - JWT-authenticated web dashboard with sales & debt analytics
- 🌐 [Live Demo](https://ledger-tau-two.vercel.app)

### 🔐 [Envrypt](https://github.com/lgndcraft2/envrypt) — *Secure Secret Management for Teams*
> A modern vault application for teams to store, share, and manage environment variables and API secrets — with end-to-end encryption and granular access control.

- **Tech:** React · TypeScript · Vite · FastAPI · Supabase (PostgreSQL) · AES-256 Encryption · Tailwind CSS · Framer Motion
- **Key Features:**
  - Secure auth via Supabase (Email/Password + Google OAuth)
  - Team roles — Owner, Admin, Member — with per-vault access control
  - Click-to-reveal secrets (never exposed in the network tab on load)
  - Bulk `.env` file import & export
  - Audit logging and CI/CD service tokens
- 🌐 [Live Demo](https://envrypt-seven.vercel.app)

### 🧠 [Synapse](https://github.com/lgndcraft2/Synapse) — *Cognitive Accessibility Chrome Extension*
> A Chrome extension powered by **Anthropic Claude** that restructures and summarizes any webpage or document to match your unique reading style and cognitive preferences — in real time.

- **Tech:** Vanilla JavaScript · HTML · CSS · Chrome Extensions API (MV3) · Anthropic Claude API (`claude-3-5-sonnet`)
- **Key Features:**
  - **Section Cards** — click any paragraph for an instant AI-tailored summary card
  - **Full Page Reformat** — transforms entire pages into clean, readable layouts
  - **Document Reader** — drag-and-drop PDFs, CSVs, and Markdown for AI-powered reading
  - **Continuous Learning** — thumbs up/down feedback automatically refines your cognitive profile
  - Onboarding flow to set reading style, detail level, structure, and tone preferences
  - Built for the **Claude Thinkathon 1.0**

### 🌾 [AgriVision AI](https://github.com/lgndcraft2/GitForce2) — *Full-Stack Agricultural Intelligence Platform*
> A hackathon-built, full-stack AI platform for farmers — combining a **Django + Gemini backend** with a **React chat & CRM frontend** to deliver crop analysis, farm insights, and an AI assistant, all in one mobile-first app.
 
- **Backend Tech:** Python · Django · Google Gemini AI · SQLite
- **Frontend Tech:** React · TypeScript · Vite · Tailwind CSS · Radix UI · Supabase · Firebase · Google Teachable Machine
- **Key Features:**
  - AI chat assistant tuned for agricultural context (crop disease, weather, market prices)
  - Image-based crop analysis using Google Teachable Machine (ML in the browser)
  - CRM panel for managing farm contacts and records
  - Insights dashboard for farm analytics
  - Mobile-first UI with dark/light theme support
  - Builr for the **Lagos Impact Hackathon**
- 🌐 [Live Demo](https://agrotech-five.vercel.app) · [Frontend Repo](https://github.com/Kenny-204/lih-tbd) · [Backend Repo](https://github.com/lgndcraft2/GitForce2)

### ✅ [Confam](https://github.com/lgndcraft2/Confam) — *AI Fact-Checking via USSD*
> *"Don't just believe it. Dial it. Confam it."* — An AI-powered USSD fact-checking service that lets anyone with a basic feature phone verify news, health claims, and rumors — no internet required.

- **Tech:** Python · Flask · Google Gemini 2.5 Flash · Google Search Grounding (RAG) · Arkesel USSD · Vercel
- **Key Features:**
  - Works on any GSM feature phone with zero internet or smartphone needed
  - Nigerian-context aware — understands local people, places, and events
  - AI powered by Gemini with live web search grounding for accurate, up-to-date verification
  - Intelligent rate-limit handling for high traffic stability
  - Built for the **Primetech Hackathon**
- 🌐 [Live USSD Endpoint](https://confam-five.vercel.app/ussd)
